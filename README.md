# Голосовой ассистент (Flutter)

Прототип ассистента, который управляет задачами, напоминаниями и встречами голосом или текстом на русском языке.

- Репозиторий: _вставьте ссылку_
- Работающий прототип (APK / демо): _вставьте ссылку_

## Возможности

| Сценарий | Примеры фраз |
|---|---|
| Создание задачи / напоминания | «Напомни завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт», «Поставь задачу купить билеты до конца недели» |
| Создание встречи | «Добавь встречу с командой завтра в 15:00», «В четверг в 11 у меня встреча с дизайнером» |
| Список за период | «Что у меня сегодня?», «Какие задачи у меня на завтра?», «Что запланировано на эту неделю?», «Есть ли у меня встречи сегодня?» |
| Поиск старых записей | «Найди задачу про презентацию», «Когда у меня была встреча с Иваном?», «Я когда-то ставил задачу по договору, найди её» |
| Бонус | уточняющие вопросы, контекст диалога («А перенеси её на завтра»), перенос, удаление, «отметь выполненной», предупреждение о пересечении встреч, выбор из нескольких найденных записей |

Относительные даты: сегодня, завтра, послезавтра, «в пятницу», «через два часа», «через 3 дня», «на следующей неделе», «до конца недели», «15 марта», «в 3 дня», «в полдень», «вечером».

Если не хватает данных, ассистент спрашивает: «Поставь встречу с Иваном завтра» → «На какое время поставить встречу?».

## Стек и архитектура

- **Flutter / Dart** (Android и iOS).
- **Речь → текст**: `speech_to_text` (системный распознаватель, `ru_RU`).
- **Текст → речь**: `flutter_tts` (системный синтезатор, `ru-RU`).
- **Понимание запроса**: правила и регулярные выражения для русского языка, работают офлайн, без ключей API.
- **Хранение**: SQLite (`sqflite`). Записи сохраняются между запусками.
- **Поиск**: нечёткий, по основам слов + словарь синонимов + допуск одной опечатки.

```
lib/
  voice/voice_service.dart       STT и TTS — только работа с речью
  nlu/                           понимание языка, без доступа к данным
    intent_parser.dart             тип действия, название, тип записи
    date_parser.dart               даты и время («завтра в 10 утра»)
    search.dart                    нечёткий поиск
  assistant/assistant.dart       бизнес-логика, диалог, уточнения, контекст
  data/entry_repository.dart     интерфейс хранилища + SQLite + in-memory
  models/entry.dart              модель записи
  ui/chat_page.dart              чат, кнопка микрофона
```

Поток данных: голос → `VoiceService` → текст → `IntentParser` (команда) → `Assistant` (действие над `EntryRepository`) → текст ответа → UI и `VoiceService.speak`.

Каждый слой заменяем: `IntentParser` можно заменить на LLM, возвращающую тот же `Command`; SQLite — на другое хранилище (интерфейс `EntryRepository`).

### Модель записи

`id`, `type` (задача / встреча / напоминание), `title`, `dueAt` + `hasTime` (дата с временем или только дата), `createdAt`, `done`.

## Запуск

```bash
flutter create . --platforms=android,ios   # один раз: сгенерирует android/ и ios/
flutter pub get
flutter run                                # на реальном устройстве (эмулятор часто без микрофона)
flutter test
```

**Android**: в `android/app/src/main/AndroidManifest.xml` внутри `<manifest>`:

```xml
<uses-permission android:name="android.permission.RECORD_AUDIO"/>
<uses-permission android:name="android.permission.INTERNET"/>
<queries>
  <intent><action android:name="android.speech.RecognitionService"/></intent>
  <intent><action android:name="android.intent.action.TTS_SERVICE"/></intent>
</queries>
```

В `android/app/build.gradle` (или `.kts`) поставьте `minSdk = 24`.

**iOS**: в `ios/Runner/Info.plist`:

```xml
<key>NSMicrophoneUsageDescription</key><string>Для голосовых команд</string>
<key>NSSpeechRecognitionUsageDescription</key><string>Для распознавания речи</string>
```

Для русского распознавания на устройстве должен быть установлен русский язык распознавания / голосовой ввод Google.

## Принятые решения

- **Правила вместо LLM.** Прототип работает без ключей, мгновенно и предсказуемо; фразы не привязаны к командам, а определяются по смыслу ключевых слов и датам. Минус — покрытие формулировок ограничено правилами.
- **Системные STT/TTS** — бесплатно и без сети (зависит от устройства).
- **Неоднозначные часы без «утра/вечера»**: 1–6 → дневное время («в 3» = 15:00), 7–23 — как сказано.
- **«В пятницу» в пятницу** — это следующая пятница.
- **Задача без времени** получает только дату; **встреча и напоминание** всегда требуют время (иначе уточняющий вопрос).
- **«На этой/следующей неделе»** при создании записи означает срок в конце этой недели.
- **Пересечение встреч**: длительность считается равной часу; ассистент предупреждает, но не блокирует создание.

## Что улучшил бы

- LLM (function calling) как основной разбор запроса, правила — как запасной вариант; эмбеддинги для настоящего семантического поиска.
- Повторяющиеся задачи и встречи; длительность встреч; часовые пояса.
- Интеграция с системным календарём, локальные уведомления для напоминаний.
- Несколько пользователей и синхронизация (облачная БД).
- Потоковое распознавание с подтверждением перед сохранением, выбор голоса.
- Больше тестов NLU на реальных фразах.
