# Веб-версия: как показать приложение без телефона и эмулятора

Веб-версия работает в браузере **Chrome или Edge**. Записи хранятся в браузере (localStorage), на телефоне — в SQLite.

## 0. Один раз подготовить проект

```
flutter create . --platforms=web
flutter pub get
```
Появится папка `web/`. Остальной код уже готов (в `main.dart` для браузера выбирается `PrefsEntryRepository`).

## Вариант A. Показать с компьютера (быстрее всего)

```
flutter run -d chrome
```
Откроется Chrome с приложением. Микрофон работает на `localhost`: при первом нажатии на микрофон разрешите доступ в адресной строке браузера.

Готовая сборка для показа без Flutter на другом ПК:
```
flutter build web --release
cd build\web
python -m http.server 8080
```
и открыть `http://localhost:8080` в Chrome (нужен Python). Открывать `index.html` двойным щелчком нельзя — приложение не запустится.

## Вариант B. Ссылка в интернете через GitHub Pages (бесплатно)

1. Закоммитьте и отправьте проект, включая папки `web/` и `.github/` (файл `.github/workflows/web.yml` уже есть в проекте):
   ```
   git add .
   git commit -m "Add web version"
   git push
   ```
2. На GitHub: **Settings → Actions → General → Workflow permissions → Read and write permissions → Save**.
3. Во вкладке **Actions** дождитесь зелёной галочки у «Deploy web» (3–5 минут). Если сборка не стартовала, нажмите «Run workflow».
4. **Settings → Pages → Source: Deploy from a branch → Branch: `gh-pages` / `(root)` → Save**.
5. Ссылка: `https://<ваш-логин>.github.io/<имя-репозитория>/` (появляется через 1–2 минуты).

Вставьте эту ссылку в README как «Работающий прототип».

## Вариант C. Без Git — перетащить папку (Netlify Drop)

1. `flutter build web --release`
2. Откройте app.netlify.com/drop и перетащите папку `build\web` в окно.
3. Netlify выдаст ссылку, она открывается с любого устройства (HTTPS, микрофон работает).

## Ограничения веб-версии

| Что | Как в браузере |
|---|---|
| Голосовой ввод | только Chrome / Edge; в Firefox и Safari распознавания речи нет (текстовый ввод работает) |
| Микрофон | нужен HTTPS или `localhost`; по адресу вида `http://192.168...` браузер его не даст |
| Уведомления | не работают (только на Android) |
| Данные | хранятся в этом браузере и не переносятся между устройствами; очистка данных сайта удаляет записи |
| Голос ответа | зависит от голосов браузера; мужской/женский — по возможности |

## Если что-то не так

| Симптом | Решение |
|---|---|
| Белый экран на GitHub Pages | Не тот `--base-href`: в workflow он берётся из имени репозитория автоматически; пересоберите, если репозиторий переименовали |
| 404 на ссылке | В Settings → Pages должна быть ветка `gh-pages`; подождите пару минут |
| Workflow упал на `flutter pub get` | Проверьте, что `pubspec.yaml` закоммичен; версия Flutter в Actions — последняя stable |
| Записи не сохраняются после перезагрузки страницы | Откройте в обычном окне, не в режиме инкогнито |
| Микрофон не включается | Разрешите микрофон для сайта (значок замка в адресной строке) и используйте Chrome/Edge |
