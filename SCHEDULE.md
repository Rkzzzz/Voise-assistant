# Расписание по фото (офлайн)

Распознавание работает на устройстве через Tesseract, интернет не нужен.

1. Скачайте файл русской модели `rus.traineddata`
   (репозиторий tesseract-ocr/tessdata_fast на GitHub, ~2 МБ).
2. Положите его в `assets/tessdata/`.
3. `flutter pub get`, затем запуск на телефоне.
4. Настройки → «Распознать расписание школьника» → снять или выбрать фото →
   проверить и поправить текст → «Разобрать текст» → «Добавить в календарь».

Фото лучше делать ровно, при хорошем свете. Таблицы Tesseract читает хуже,
чем обычный текст, поэтому текст всегда можно поправить вручную перед добавлением.
